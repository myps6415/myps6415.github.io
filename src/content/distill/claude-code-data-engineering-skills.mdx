Data With Baraa 的 GitHub repo 放了 16 個給資料工程師用的 Claude Code skill，安裝方式是把 skills 資料夾複製到專案的 .claude/skills，或用 /plugin 裝成外掛。

這批 skill 對應的都不是寫程式，而是工程師真正的雜事：新資料源進來先 profile、管線壞了查 incident、上線前跑 impact、把資料給別人用時生 data-product。每個 skill 就是一份 SKILL.md，寫清楚輸入、步驟、輸出，連「絕不碰什麼」都列出來，多數跑完產出一頁網頁，能直接開來看、轉給同事。

其中 7 個來自作者的 YouTube 頻道影片，示範用的是虛構公司。目前是第一版，plugin 更新不會自動，得自己 pull。

skill 刻意寫得通用，沒有你的路徑與標準，得自己加。它的價值在於把每次都要重想一遍的流程，變成可以複製的起點。MIT 授權，拿一條管線試一次成本很低。
