2007 年，資料庫先驅 Jim Gray 描述科學的第四典範：探索一個人腦放不下的資料尺度。他真正想講的不是資料，是工具。二十多年過去，管線仍然擋在一個好奇的人跟答案之間。

Avaloka 試著造這支工具。你用白話問問題，一組分工的代理輪流上：規劃、剖析、寫程式、驗證、執行、訓練、視覺化。

我最有興趣的是它怎麼處理自信的錯誤。README 坦承早期版本在純雜訊資料上回傳 pass，把什麼都沒學到的模型認成可上線；他們自己的 benchmark 在修正前後都是 1.00，因為沒有任何一題碰到那個觸發條件。評估不看平均值，看的是信賴區間，多數類別分類器就沒法靠浮點雜魚蒙混過關。

安裝只要兩條指令，不要 API key 也不要雲端帳號，Python 3.11 或 3.12，五到十分鐘跑完設定，資料留在自己機器上。

值得試一次的理由很單純：讓它解一個你手邊的真問題，然後打開 lineage.json，看每個數字從哪裡來。
