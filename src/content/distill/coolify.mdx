一個 curl 指令，Coolify 團隊就把 Heroku、Netlify、Vercel 搬到你自己的機器上。

自架常被想像成先學 Docker，再養一台 24 小時開機的機器。Coolify 反過來：有 SSH 連線就能跑，VPS、裸機、連 Raspberry Pi 都行。設定留在自己機器上，哪天不想用，服務照樣活著。

原始碼從 GitHub 拉就能部署，資料庫受管，另有 360 多個一鍵服務。部署可綁在 Git push 自動跑，也能開 pull request 預覽。

網域、自動 HTTPS、反向代理與容器終端機都在內。

我在意的是那句自由度：設定留在自己機器上、不用時資源仍可管理，是刻意的立場。

我覺得賣點不是功能表長，而是把「用別人的雲」和「自己扛維運」之間那段灰色地帶，用一個 SSH 連線當入口。

安裝只要一行指令，腳本也先攤開給你檢查。不想養主機，可選付費的 Coolify Cloud。

我建議你挑一個小服務試著搬，跑一週再決定要不要認養。
