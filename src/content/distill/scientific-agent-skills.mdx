讓 AI coding agent 變成研究搭檔——這個開源專案最近在 GitHub 爆紅。

K-Dense-AI/scientific-agent-skills 把 163 個科學研究技能包裝成 AI agent 可直接呼叫的技能庫。分子對接、文獻檢索、基因體分析、藥物動力學建模，全部有現成技能文件加可執行範例，不用自己查 API 文件。

每個技能都有 `SKILL.md` 說明工作流程與驗證方式，讓 AI 在科學任務上不只是「大概會」，而是「可以交付」。

涵蓋 78 個以上科學資料庫：PubChem、ChEMBL、UniProt、ClinicalTrials.gov。跨領域組合靠幾個技能就能串起來，不用從頭整合。

支援 Cursor、Claude Code、Codex。多數工程師不需要改變現有工作流，只要把技能目錄設定進去，就能讓 AI coding agent 多了科學研究能力。

以前需要整個團隊處理的跨領域研究，現在靠這個開源工具加上自己的 API key，個人研究者也能做到。
